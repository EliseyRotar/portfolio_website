## Caratteristiche

- HTML5 semantico, CSS3, Bootstrap 5.3
- Dark theme con contrasto WCAG AA
- Animazioni on-scroll (AOS) con rispetto di `prefers-reduced-motion`
- SEO completo: meta description, Open Graph, Twitter Card, JSON-LD `Person`
- `sitemap.xml`, `robots.txt`, canonical URL
- Pagina 404 personalizzata
- Form di contatto via Formspree
- `loading="lazy"`, `width`/`height` espliciti per evitare CLS
- Skip link, focus-visible ring, ARIA labels

## Stack tecnico

- HTML5 semantico (header, main, section, article, footer)
- CSS3 custom properties, `prefers-reduced-motion`, mobile-first
- Bootstrap 5.3 + Bootstrap Icons
- AOS (Animate On Scroll)
- Formspree (form di contatto)
- Deploy: GitHub Pages (branch `main`, root)

## Sezioni

1. **Home** — Hero con headline ruolo + CTA
2. **Chi Sono** — Bio concreta con evidenze (non "passionate about coding")
3. **Competenze** — 6 card, ogni tech legata a un progetto reale
4. **Progetti** — 4 in evidenza (Ecolens, Music Sync, JARVIS AI, eli6_movies) + link a tutti i 38 repo
5. **Percorso** — Formazione + status attuale (RUNNING / OPTIMIZING / SECURED / TRACKING)
6. **Contattami** — Form + email diretta

## Pubblicazione su GitHub Pages

1. Vai su **Settings → Pages** del repository
2. **Source**: `Deploy from a branch`
3. **Branch**: `main` · cartella `/ (root)` · Save
4. Attendi ~1 minuto, il sito è live
